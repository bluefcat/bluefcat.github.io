```cpp
int result = 0;
for(int x = a; x <= b; x ++){
  for(int y = c; y <= d; y ++){
    result += (gcd(x, y) == 1);
  }
}
```
에서
```cpp
for(int y = c; y <= d; y ++){
    result += (gcd(x, y) == 1);
}
```
부분을 
```cpp
int sub_solution(int p, int q){
  int result = 0;
  for(int x = 1; x <= p; x ++){
    for(int y = 1; y <= q; y ++){
      result += (gcd(x, y) == 1);
    }
  }
  return result;
}
```
로 구성된 함수 하나만 잘 가지고 있어도 된다는 것을 알 수 있음.
```cpp
for(int y = 1; y <= q; y ++) result += (gcd(x, y) == 1));
```
이 부분이 사실상 오일러 phi 함수와 동치
```cpp
for(int y = 1; y <= q; y ++) if(x % y == 0) result += mobius[y ] * (x/y);
```
그리고 저 loop를 다시 약수를 카운트 하는거에서 배수로 카운트하는걸로 바꾼다음에 result += ... 이부분을 밖으로 빼고 수식 정리하면 풀이 흐름.
